# BUG-015 — Refund lifecycle events were not delivered to webhook consumers

**Severity:** High — merchants and downstream systems miss refund outcomes  
**Area:** FP-300, webhooks

## Finding

The refund service enqueued `refund.succeeded`, but the webhook dispatcher excluded that type and envelope construction had no mapping for it.

## Fix

Added `refund.succeeded` to the dispatcher allowlist and event envelope mapping, with regression coverage. This is specifically required to complete the FP-300 refund lifecycle.

## Verification

TypeScript typecheck passes. Dispatcher DB-backed tests require PostgreSQL and were unavailable.
