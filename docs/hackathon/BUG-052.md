# BUG-052: CloseBatch did not journal scheme truncation residue

**Severity:** High  
**Component:** settlement / ledger (ADR-0002)  
**Status:** Fixed and verified

## Evidence

ADR-0002 requires a balanced group per export line: credit `card_scheme_clearing`, debit `scheme_rounding_residue` for `gross_fils - amount_fils`. HANDOVER states residue posting inside CloseBatch was never finished. Finance memo: scheme statement always a few fils **over**. Truncation of the scheme file (BUG-013) without the journal still leaves the ledger uncleared.

## Fix

After each `scheme_export_lines` insert, if residue > 0, CloseBatch inserts the ADR-0002 pair keyed to the batch and transaction. Zero residue is skipped (`amount_fils > 0` check). Existing payout-leg counts stay at 2 for already-truncated amounts (10000, 6000 fils).
