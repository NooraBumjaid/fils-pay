# BUG-007 — Compose did not load the documented API environment file

**Severity:** High for deployment readiness  
**Status:** Fixed in this branch

## Evidence

The Compose comments and operations guide said `ops/.env.docker` was loaded
automatically, but no service had an `env_file` entry. The API therefore did
not receive its documented `NODE_ENV` or acquirer callback signing secret.
In production this could prevent startup; in other configurations it could
leave callback authentication settings at unsafe defaults.

## Fix and coverage

The API service now explicitly loads `ops/.env.docker`. Deployment-only
settlement and webhook encryption secrets are mapped from the process
environment, and the guide documents the required values. API config fails
closed for required production secrets. Compose regression coverage asserts
the env file is attached.
