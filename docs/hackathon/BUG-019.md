# BUG-019 — Scheme export decimal and integer amounts could disagree

**Severity:** High — reconciliation amount mismatch  
**Area:** Settlement exports

## Finding

Scheme export rows stored `amount_fils` after truncating to the scheme's supported amount precision but rendered the decimal `amount` from the untruncated gross. Consumers could receive two different amounts for the same line.

## Fix

Render the scheme decimal amount from the same truncated fils value stored in `amount_fils`.

## Verification

The settlement package database-backed tests pass against the isolated migrated PostgreSQL database.
