# BUG-004 — Production accepts unsigned acquirer callbacks by default

**Severity:** Critical security exposure  
**Status:** Fixed in this branch

## Evidence

The public fraud-review callback has no session or API-key authentication;
HMAC verification is its only authentication. `loadConfig` defaulted
`ACQUIRER_CALLBACK_REQUIRE_SIGNATURE` to `false` for every environment,
even though the production config separately requires a signing secret. An
unsigned callback could therefore reach the application path in production.

## Fix and coverage

Signature enforcement now defaults to enabled in production and disabled in
development. Operators can still explicitly configure the flag for a
verified integration transition. `apps/api/src/config.test.ts` covers the
production default, development default, and explicit override.
