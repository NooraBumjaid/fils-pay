# BUG-005 — Compose images could not be built

**Severity:** High for deployment readiness  
**Status:** Fixed in this branch; image builds pending Docker availability

## Evidence

`ops/docker-compose.yml` referenced `ops/Dockerfile.node` and
`ops/Dockerfile.go`, but neither file existed in the tracked repository.
Every service using those build contexts failed before startup.

## Fix and coverage

Added a Node image for the API, reporting worker, migration, and seed
commands, and a multi-stage Go settlement image. `.dockerignore` excludes
the checked-in `ops/.env.docker` and local environment files from build
contexts. Static Compose regression coverage checks both files exist.

Docker image builds could not be run in this environment because Docker
Desktop's engine is unavailable.
