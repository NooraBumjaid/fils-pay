# BUG-002 — Fresh database migration stops at chart account seed

**Severity:** High for bootstrap and upgrades  
**Status:** Fixed in this branch; live PostgreSQL verification pending

## Evidence

Migration `0055_chart_of_accounts_suspense.sql` inserted into `code`,
`account_type`, and `description`, then conflicted on `code`. The schema
created by `0007_ledger_double_entry.sql` has only `id`, `name`, and `kind`;
`kind` accepts `asset`, `liability`, or `revenue`. Thus PostgreSQL rejects
0055 before any later migration can run.

## Fix

Seed the two suspense accounts using the existing `id`, `name`, and `kind`
columns, classify them as assets, and make the insert idempotent on `id`.
The chart schema and frozen money packages are unchanged.

## Regression coverage

`scripts/migrationContracts.test.ts` checks the seed against the base chart
schema. It passes locally. A real migration apply could not be run because
Docker is unavailable in this environment.
