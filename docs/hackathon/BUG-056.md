# BUG-056: Lifetime payout estimate used REAL and drifted

**Severity:** Medium  
**Component:** settlement monitoring  
**Status:** Fixed and verified

## Evidence

Finance memo: “Lifetime payout estimate drifts for high-volume merchants.” Column was `REAL`. `UpdateLifetimePayoutMonitoringEstimate` added `float32`. Integers above 2^24 are not exact in float32.

## Fix

Migration `0079` converts the column to `BIGINT`. Go adds `int64` fils. The locked small-value test still scans 51000 successfully.

## Tests

Docker `TestUpdateLifetimePayoutMonitoringEstimate` (small locked + large new) — pass.
