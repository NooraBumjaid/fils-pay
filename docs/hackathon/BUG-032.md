# BUG-032 — Refund ceiling included uncaptured authorization

**Severity:** Critical — potential refund of funds never captured
**Area:** FP-300, payment accounting

## Finding

Refundable balance was computed as authorized amount minus prior refunds. For a partial capture, this allowed refunding the uncaptured portion of the authorization.

## Fix

Compute the ceiling as captured fils minus already refunded fils. Preserve exact integer money arithmetic through the existing money package.

## Verification

Added regression cases for refunding beyond partial capture and repeated partial refunds exceeding the remaining captured balance. Refund validation tests and workspace typecheck pass.
