# BUG-037 — Settlement payable calculation used float32

**Severity:** High — payout amount could drift for large values
**Area:** Financial correctness, settlement

## Finding

`NetPayableFils` converted integer fils to `float32` to subtract fees, losing integer precision for sufficiently large totals.

## Fix

Calculate payable as exact integer subtraction and add unit cases for large amounts and negative refund-adjusted payable.

## Verification

Added Go unit tests for a large exact amount and a negative refund-adjusted payable. `go test ./internal/settlement` passes inside a temporary Go container against the isolated migrated PostgreSQL database.
