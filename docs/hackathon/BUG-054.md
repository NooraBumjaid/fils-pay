# BUG-054: Support admins could create credits that post payable immediately

**Severity:** High  
**Component:** admin credits  
**Status:** Fixed and verified

## Evidence

Incident: “some admin actions don't seem to have the right role checks.” `createCreditRequest` is documented as finance/super_admin, and below-threshold credits post ledger legs immediately. `POST /v1/admin/merchants/:id/credits` only required a session. Approve/reject were gated; create was not.

## Fix

Move the create route into the finance/super_admin register. Support can still read the queue.

## Tests

`credits.supportCreate.new.test.ts` — support POST returns 403. Locked finance create and support approve/reject tests still pass.
