# BUG-055: Disabled admin could keep an impersonation grant

**Severity:** High  
**Component:** admin impersonation  
**Status:** Fixed and verified

## Evidence

`lookupImpersonationGrant` did not join `admin_users.status = 'active'`. The comment claimed a disable trigger revoked grants; no such trigger exists.

## Fix

Require `au.status = 'active'` on lookup, matching authenticated admin sessions.
