# BUG-051: Duplicate settlement payout disbursement rows

**Severity:** High  
**Component:** payout rail / webhooks  
**Status:** Fixed and verified

## Evidence

Incident 2026-08-21: two processes both thought they were first. `settlement_payout_disbursements` had only a non-unique index on `settlement_batch_id`. `recordPayoutDisbursementEffect` inserted on every first-attempt `settlement.paid` delivery.

## Fix

Migration `0078` unique index `uq_settlement_payout_disbursements_batch`. Insert uses `ON CONFLICT (settlement_batch_id) DO NOTHING`.

## Regression coverage

`payoutDisbursement.dup.new.test.ts`: sequential and concurrent double record leave one row. **2 pass / 0 fail.**
