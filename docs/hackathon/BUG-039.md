# BUG-039 — Node service image could not install dependencies

**Severity:** High — container build and deployment blocked
**Area:** Operations, deployment readiness

## Finding

The Node image used Node 20 although a locked dependency requires Node 22 or newer. Its `npm ci` also failed to build the native `argon2` package because the image lacked Python and a C/C++ toolchain.

## Fix

Use the Node 22 Bookworm image and install the minimal Python/make/g++ build prerequisites before `npm ci`.

## Verification

The container image now builds successfully with `npm ci`. The initial image build failed on missing Python; the updated build completed. The database migration job still needs a fresh isolated test volume because the default local volume was initialized with a different password.
