# BUG-040 — Payment-link cancellation was not merchant-scoped

**Severity:** High — cross-merchant mutation
**Area:** Payment links

## Finding

Cancellation updated a payment link by UUID and active status alone. A merchant who obtained another merchant's link UUID could cancel it.

## Fix

Scope both the cancellation update and its follow-up status lookup by the authenticated merchant ID.

## Verification

Added a route regression that attempts cancellation as a different merchant, expects 404, and confirms the owner's link remains active. The payment-link route suite passes 19/19 against isolated PostgreSQL.
