# BUG-060: JPEG named `.pdf` accepted as commercial_registration

**Severity:** High  
**Component:** KYC upload  
**Status:** Fixed and verified

## Evidence

FH: a jpeg named `cr.pdf` passes the PDF-only check. The gate was `fileName.endsWith(".pdf")` after `detectFileType` had already accepted jpeg/png/pdf. MK’s note that detectFileType rejects non-PDF bytes for these document types is true only for files with no magic; a real JPEG is a detected type.

Locked `app.test.ts` covers a non-PDF *filename* with real PDF bytes, not a JPEG with a `.pdf` name.

## Fix

PDF-only types require `detected === "pdf"` and a `.pdf` filename.

## Tests

`kyc.pdfOnly.new.test.ts` — pass. Locked KYC filename test still pass.
