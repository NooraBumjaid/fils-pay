# BUG-006 — Compose exposed PostgreSQL on every host interface

**Severity:** High for deployment security  
**Status:** Fixed in this branch

## Evidence

Compose published `5432:5432`, which binds the database port on all host
interfaces. Its password is a local development default, so a hosted machine
could expose the database to networks outside the Compose bridge.

## Fix and coverage

The published port now binds to `127.0.0.1`; services continue using the
private Compose network. The Compose contract regression checks the loopback
binding and rejects the previous all-interface mapping.
